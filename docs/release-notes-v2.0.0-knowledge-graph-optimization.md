## ✨ 新功能

### 1. 权重算法 v2

**问题**: 旧算法中时间关联权重过高（1.0，1分钟内 boost 1.5倍），超过关键词和标签关联权重

**解决方案**: 全新的权重算法

| 关联类型 | 旧权重 | 新权重 | 提升条件 |
|---------|--------|--------|----------|
| 语义 | 1.0 | 1.0 | - |
| 标签 | 1.0 | **0.85** | - |
| 关键词 | 1.0 | **0.8** | fallback 0.5 → **0.7** |
| 收藏夹 | - | **0.5** | 动态权重（防止大收藏夹爆炸） |
| 领域 | 0.4 | 0.4 | - |
| 时间 | 1.0 | **0.3** | 1分钟内 × **1.2**（原 1.5） |

**收藏夹关联动态权重公式**:
```
weight = 0.5 × (3.0 / max(count, 3.0))

示例：
- 2 篇文章 → 0.5
- 10 篇文章 → 0.15
- 100 篇文章 → 0.015
```

### 2. 迁移系统

全新的权重版本迁移系统，支持从 v1 平滑升级到 v2：

**特性**:
- ✅ 幂等性保证（重复调用安全）
- ✅ 进度跟踪（实时进度条）
- ✅ 可中断（支持取消）
- ✅ 回滚支持（一键回退到 v1）
- ✅ 性能监控（1000篇文章 < 5分钟）

**API**:
```rust
// 查询迁移状态
get_migration_stats() -> MigrationStats

// 检查迁移是否进行中
is_migration_in_progress() -> bool

// 开始迁移（异步）
migrate_associations_to_v2(options: MigrationOptions)

// 回滚到 v1
rollback_v2_associations()
```

### 3. 文章关联预览组件

在文章阅读页面左下角显示当前文章的关联节点列表：

**功能**:
- 🔍 显示前 10 条最相关联的文章
- 🎨 类型图标（语义、标签、收藏夹、时间）
- 💪 权重可视化（圆点大小和透明度）
- 🔗 点击跳转到关联文章

### 4. 图谱焦点模式

**操作**: 双击任意节点

**效果**:
- 只显示该节点及其直接关联（1层）
- 再次双击或点击空白处退出焦点模式

### 5. 图谱统计面板

**显示指标**:
- 节点数、边数
- 平均度、平均权重
- 连通分量数
- 各类型关联的数量分布
- 图例说明

## 🐛 问题修复

### 类型安全

- **修复**: GraphView.tsx 中的双重类型断言（`as unknown as`）
- **解决**: 使用类型守卫进行类型安全的访问

### 内存泄漏

- **修复**: MigrationProgress 组件的事件监听器清理
- **解决**: 正确处理 Tauri 事件监听器的 Promise

### 错误处理

- **修复**: Rust 代码中的 `unwrap()` 可能导致 panic
- **解决**: 使用 `expect()` 提供清晰的错误消息

### SQL 安全

- **验证**: 所有 SQL 查询使用参数化查询
- **确认**: 无 SQL 注入风险

## 📖 升级指南

### 自动迁移

首次启动新版本时，应用会自动检测并提示迁移：

1. **轻度用户**（<100 篇文章）
   - 应用启动时自动迁移
   - 完成时间：<1 分钟
   - 用户体验：无感知

2. **中度用户**（100-500 篇文章）
   - 用户空闲 15 分钟后触发
   - 完成时间：5-10 分钟
   - 用户体验：后台静默迁移

3. **重度用户**（500+ 篇文章）
   - 夜间时段（2-6am）自动触发
   - 或用户手动触发
   - 完成时间：30 分钟+
   - 用户体验：显示进度，支持取消

### 手动触发迁移

在知识图谱页面，点击"立即更新关联"按钮。

### 回滚

如果迁移后发现问题，可以在设置中选择"回滚到旧版本关联"。
