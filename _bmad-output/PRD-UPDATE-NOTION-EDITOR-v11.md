## 🏗️ 新增技术架构

### 编辑器架构概览

```
用户界面层 (UI Layer)
    ↓
编辑器核心层 (Editor Core)
    └── Slate.js / ProseMirror + React + Zustand
    ↓
块处理层 (Block Processing Layer)
    └── 块类型、块操作、块渲染
    ↓
数据存储层 (Data Storage Layer)
    └── SQLite + 版本历史 + 自动保存
```

### 核心模块设计

#### 模块 1: 块类型系统

**块抽象接口**:

```typescript
type Block = {
  id: string                    // 唯一标识
  type: BlockType               // 块类型
  content: BlockContent          // 块内容
  style: BlockStyle             // 块样式
  metadata: BlockMetadata       // 块元数据
  children?: Block[]            // 子块（支持嵌套）
  position: number             // 在兄弟节点中的位置
}

type BlockType =
  | 'paragraph'     // 纯文本
  | 'heading'        // 标题 (h1-h6)
  | 'quote'          // 引用
  | 'code'           // 代码块
  | 'bullet-list'    // 无序列表
  | 'numbered-list'  // 有序列表
  | 'to-do'         // 任务列表
  | 'image'          // 图片
  | 'table'          // 表格
  // ... 更多块类型
```

#### 模块 2: 命令菜单系统

**命令菜单触发**:

```
用户输入 "/" → 检测触发 → 显示命令菜单 → 模糊搜索 → 选择命令 → 插入块
```

**命令分类**:
- 基础块: 文本、标题、列表、引用等
- 媒体块: 图片、视频、文件等
- 结构块: 表格、分栏、公式等
- 高级块: 日期、提醒、标签等

#### 模块 3: 块操作引擎

**核心操作**:

```typescript
type BlockOperation =
  | { type: 'insert'; block: Block; position: number }
  | { type: 'delete'; blockId: string }
  | { type: 'update'; blockId: string; updates: Partial<Block> }
  | { type: 'move'; blockId: string; newPosition: number }
  | { type: 'indent'; blockId: string }
  | { type: 'merge'; blockIds: string[] }
  | { type: 'split'; blockId: string; position: number }
```

#### 模块 4: 性能优化策略

**渲染优化**:
- 虚拟滚动: 仅渲染可见块
- React.memo: 避免不必要的重渲染
- 增量渲染: 使用 requestIdleCallback

**数据优化**:
- 防抖保存: 1 秒防抖，减少 I/O
- 批量操作: 批量数据库操作
- 索引优化: page_id + position 复合索引
- 缓存策略: 内存缓存热数据

## 🗄️ 新增数据模型 (3 个新表)

### 页面表 (pages)

```sql
CREATE TABLE pages (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL DEFAULT 'Untitled',
  icon TEXT,                      -- 图标（emoji）
  cover_image TEXT,               -- 封面图片 URL
  parent_id TEXT,                 -- 父页面 ID（支持层级）
  position INTEGER NOT NULL,      -- 在兄弟节点中的位置
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL,
  template_id TEXT,               -- 基于哪个模板创建

  FOREIGN KEY (parent_id) REFERENCES pages(id) ON DELETE SET NULL
);
```

### 块表 (blocks)

```sql
CREATE TABLE blocks (
  id TEXT PRIMARY KEY,
  page_id TEXT NOT NULL,
  type TEXT NOT NULL,             -- 块类型
  content TEXT,                   -- 块内容（JSON）
  style TEXT,                     -- 块样式（JSON）
  metadata TEXT,                  -- 块元数据（JSON）
  parent_block_id TEXT,           -- 父块 ID（支持嵌套）
  position INTEGER NOT NULL,      -- 在兄弟节点中的位置
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL,

  FOREIGN KEY (page_id) REFERENCES pages(id) ON DELETE CASCADE,
  FOREIGN KEY (parent_block_id) REFERENCES blocks(id) ON DELETE CASCADE
);
```

### 版本历史表 (block_versions)

```sql
CREATE TABLE block_versions (
  id TEXT PRIMARY KEY,
  block_id TEXT NOT NULL,
  page_id TEXT NOT NULL,
  content TEXT NOT NULL,          -- 块内容快照（JSON）
  style TEXT NOT NULL,            -- 块样式快照（JSON）
  created_at INTEGER NOT NULL,
  change_type TEXT NOT NULL,      -- create/update/delete/move

  FOREIGN KEY (block_id) REFERENCES blocks(id) ON DELETE CASCADE,
  FOREIGN KEY (page_id) REFERENCES pages(id) ON DELETE CASCADE
);
```

## 🎨 编辑器核心特性

### 块级编辑 (Block-based Editing)

**什么是块级编辑？**

所有内容元素都被抽象为独立的"块"：
- 一段文字是一个块
- 一张图片是一个块
- 一个表格是一个块
- 一个列表项是一个块

**块级编辑的优势**:

| 优势 | 说明 |
|------|------|
| **灵活性** | 每个块独立管理，可自由移动和重排 |
| **可扩展性** | 新增块类型无需修改核心架构 |
| **一致性** | 所有操作都基于统一的块抽象 |
| **可组合性** | 块可以嵌套，支持复杂结构 |

### 命令菜单 (Command Menu)

**使用方式**:

1. 输入 `/` 唤起命令菜单
2. 继续输入进行模糊搜索（如 `/heading` 或 `/h1`）
3. 使用 ↑↓ 选择，Enter 确认，Esc 取消
4. 支持快捷键快速选择

**支持的命令类别**:

- **基础块**: 文本、标题、列表、引用、代码
- **媒体块**: 图片、视频、文件、PDF
- **结构块**: 表格、分栏、目录、公式
- **智能块**: 日期、提醒、标签、关联

### 快捷键支持 (Keyboard Shortcuts)

**文本格式化**:
- `Cmd/Ctrl + B`: 加粗
- `Cmd/Ctrl + I`: 斜体
- `Cmd/Ctrl + U`: 下划线
- `Cmd/Ctrl + Shift + S`: 删除线

**块操作**:
- `Enter`: 创建新块
- `Backspace`: 删除空块
- `↑↓`: 在块间移动
- `Tab`: 缩进块
- `Shift + Tab`: 取消缩进

**Markdown 语法**:
- `# ` + `Space`: 一级标题
- `- ` + `Space`: 无序列表
- `1. ` + `Space`: 有序列表
- `> ` + `Space`: 引用块
- ` ``` `: 代码块

### 沉浸式编辑 (Immersive Editing)

**专注模式**:
- 全屏模式: 隐藏所有 UI 元素
- 专注模式: 高亮当前块，其他块变暗
- 打字机模式: 当前行始终居中
- 暗色模式: 保护眼睛

**辅助功能**:
- 自动保存: 实时保存，无需手动保存
- 编辑器宽度调整: 窄、中、宽、全宽
- 字体大小缩放: 适应不同视力需求
