# 最终冲突检查报告

**检查时间：** 2025-12-25
**检查范围：** PRD、技术规范、实际实现、架构文档

## 检查结果总结

发现 **5 类冲突**，其中 **1 个已解决**，**4 个需要更新 PRD**。

---

## ✅ 已解决的冲突

### 1. Embedding 模型（语义相似关联）

**状态：** ✅ **无冲突**

- **PRD FR167**: 系统可以支持本地 Embedding 模型（如 all-MiniLM-L6-v2，23MB）
- **技术规范**: 语义相似关联基于本地 Embedding 模型计算
- **实际实现**: Rust 后端使用本地 Embedding 模型进行语义相似度计算

**结论：** 语义相似关联仍使用本地 Embedding 模型，这是合理的，因为：

- Embedding 用于搜索和图谱语义相似度计算
- 需要离线可用
- 模型较小（23MB），可以本地加载

---

## 🔴 需要更新 PRD 的冲突

### 2. AI 内容理解模型选择

**冲突级别：** 🔴 **严重**

**PRD 要求：**

- FR169: 系统可以支持本地摘要生成模型（如 Phi-2，可选）
- FR171: 用户可以在设置中选择 AI 模型：**本地模型、云端 API、混合模式**
- FR196: 系统可以在网络 API 调用失败时，**自动切换到本地模型**

**实际实现：**

- 仅支持云端 API（OpenAI、Anthropic、自定义）
- 无本地模型选项
- 无混合模式

**建议更新：**

```markdown
- **FR170**: 系统可以支持可选云端 API（用户自带 API Key，如 OpenAI、Anthropic）✅
- ~~FR169~~: 系统可以支持本地摘要生成模型（如 Phi-2，可选）⏳ 未来版本
- ~~FR171~~: 用户可以在设置中选择 AI 模型：本地模型、云端 API、混合模式 ⏳ 当前仅支持云端 API
- ~~FR196~~: 系统可以在网络 API 调用失败时，自动切换到本地模型 ⏳ 当前使用提取式降级方案
```

---

### 3. 算法实现方式

**冲突级别：** 🟡 **中等**

**PRD 要求：**

- FR128: 系统可以基于内容语义（**Embedding 聚类**）生成标签
- FR129: 系统可以基于关键词提取（**TF-IDF/TextRank**）生成标签
- FR147: 系统可以基于 **TF-IDF 算法**提取关键词
- FR148: 系统可以基于 **TextRank 算法**提取关键词
- FR154: 系统可以基于 **Embedding 聚类**识别主题
- FR155: 系统可以基于 **LDA（潜在狄利克雷分配）**识别主题

**实际实现：**

- 全部使用 AI 生成（`generateObject`）
- `extractionMethod` 固定为 `'ai'`
- 无传统算法实现

**建议更新：**

```markdown
- **FR127**: 系统可以为收集的内容自动生成 2-5 个相关标签 ✅（使用 AI 生成）
- ~~FR128~~: 系统可以基于内容语义（Embedding 聚类）生成标签 ⏳ 当前使用 AI 生成
- ~~FR129~~: 系统可以基于关键词提取（TF-IDF/TextRank）生成标签 ⏳ 当前使用 AI 生成

- **FR146**: 系统可以自动提取内容的关键词（5-10 个）✅（使用 AI 提取）
- ~~FR147~~: 系统可以基于 TF-IDF 算法提取关键词 ⏳ 当前使用 AI 提取
- ~~FR148~~: 系统可以基于 TextRank 算法提取关键词 ⏳ 当前使用 AI 提取

- **FR153**: 系统可以自动识别内容的主要主题（1-3 个）✅（使用 AI 识别）
- ~~FR154~~: 系统可以基于 Embedding 聚类识别主题 ⏳ 当前使用 AI 识别
- ~~FR155~~: 系统可以基于 LDA（潜在狄利克雷分配）识别主题 ⏳ 当前使用 AI 识别

**数据模型说明：**
- `extraction_method` 字段当前仅支持 `'ai'`，`'tfidf'` 和 `'textrank'` 为未来规划
```

### 4. 性能要求

**冲突级别：** 🟡 **中等**

**PRD 要求：**

- FR185: 系统可以单篇内容的 AI 处理时间 **< 3 秒（本地模型）**
- FR1221: AI 摘要生成 < 3s（本地模型）
- FR1222: AI 标签生成 < 2s（本地模型）

**技术规范要求：**

- AI 摘要生成：< 5s（云端 API）
- AI 标签生成：< 5s（云端 API）
- AI 内容分类：< 5s（云端 API）

**建议更新：**

```markdown
- **FR185**: 系统可以单篇内容的 AI 处理时间 < 5 秒（云端 API）✅（更新：从 3s 改为 5s）
- **FR1221**: AI 摘要生成 < 5s（云端 API）✅（更新：从 3s 改为 5s）
- **FR1222**: AI 标签生成 < 5s（云端 API）✅（更新：从 2s 改为 5s）

**说明：** 云端 API 响应时间受网络影响，5s 为合理上限。
```
