## 简介

**记忆外挂**（Memory Prosthetic）是一款本地优先的知识管理工具，帮助您收集、组织和搜索个人知识内容。本指南将帮助新用户和开发者快速上手，完成从环境搭建到端到端功能使用的全过程。

该应用由桌面应用和浏览器扩展两部分组成，通过语义搜索和知识图谱技术，让您能够轻松找回任何记忆。

**核心功能**：
- 📥 一键收集网页内容
- 🔍 语义化搜索（基于本地AI嵌入）
- 📁 通过收藏夹和标签组织内容
- 🗺️ 可视化知识图谱
- 🔌 通过MCP协议集成AI助手

在开始之前，请确保您的系统已安装以下依赖项：

| 工具 | 最低版本 | 安装说明 |

#### macOS
```bash

# 安装 Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

#### Linux
```bash

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 安装 Bun
curl -fsSL https://bun.sh/install | bash
```

```powershell

# 安装 Rust (通过 rustup-init.exe)
```


## 启动开发服务器

### 1. 启动桌面应用

桌面应用基于Tauri框架构建，使用React作为前端，Rust作为后端。

```bash
# 启动桌面应用开发服务器
bun run dev:desktop
```

此命令会：
- 启动Vite开发服务器（默认端口：1420）
- 启动Tauri应用并连接到开发服务器
- 打开主窗口和搜索窗口

您也可以直接在`apps/desktop`目录下运行：
```bash
cd apps/desktop
bun run dev
```

### 2. 启动浏览器扩展

浏览器扩展基于WXT框架构建，兼容Chrome和Firefox。

```bash
# 启动浏览器扩展开发服务器
bun run dev:browser-extension
```

此命令会：
- 启动WXT开发服务器（默认端口：3000）
- 生成开发版本的扩展包
- 提供热重载功能

### 3. 同时启动两个应用

```bash
# 在两个终端窗口中分别运行
bun run dev:desktop
bun run dev:browser-extension
```

**配置说明**：
- 桌面应用配置：`apps/desktop/src-tauri/tauri.conf.json`
- 浏览器扩展配置：`apps/browser-extension/wxt.config.ts`

## 基本功能演示

本节将指导您完成一次完整的“从网页收集到搜索”的端到端流程。

### 1. 收集网页内容

1. 打开任意网页（如新闻文章、技术博客等）
2. 点击浏览器工具栏中的**记忆外挂**扩展图标
3. 点击弹出窗口中的“收集”按钮
4. 系统会自动提取页面主要内容并保存到桌面应用中

**技术流程**：
```
用户点击 → 扩展弹出窗口 → content.ts 发送 EXTRACT_CONTENT 消息 → 提取页面内容 → 发送到桌面应用 → 保存到SQLite数据库 → 生成嵌入向量
```

### 2. 在桌面应用中查看收集的内容

1. 启动桌面应用
2. 默认会显示“全部”视图，您可以看到刚刚收集的内容
3. 内容卡片会显示标题、URL、创建时间和预览摘要

### 3. 执行语义搜索

1. 在主界面顶部的搜索栏中输入与收集内容相关的关键词
2. 按回车或点击搜索按钮
3. 系统会返回语义上相关的结果，而不仅仅是关键词匹配

```typescript
// 搜索功能的核心流程
用户输入 → SearchBar → useSearch() → invoke("search", { query, filters })
                                        │
                                        ▼
                                embedding::encode(query)
                                        │
                                        ▼
                            db::vectors::similarity_search()
                                        │
                                        ▼
                            db::collections::get_by_ids()
                                        │
                                        ▼
                            db::apply_filters(filters)
                                        │
                                        ▼
                            返回结果 → ResultList
```

### 4. 验证搜索结果

搜索结果会包含：
- **标题**：内容的标题
- **类型**：区分是收集的网页还是用户笔记
- **时间**：创建时间
- **相似度**：与查询的语义相似度分数
- **预览**：内容摘要

**API端点**：
- `POST /api/search` - 语义搜索
- `GET /api/collections` - 获取收集列表
- `GET /api/health` - 健康检查

## 调试技巧

### 1. 查看应用日志

使用提供的`view-logs.sh`脚本查看应用日志：

```bash
# 运行日志查看脚本
bun run view-logs

# 或直接执行脚本
./scripts/view-logs.sh
```

该脚本会显示：
- 应用数据目录位置
- 系统日志中的错误和警告
- 崩溃报告
- 实时日志监控命令

### 2. 桌面应用调试

```bash
# 启用Rust日志（调试级别）
RUST_LOG=debug bun run dev:desktop

# 在开发者工具中查看前端日志
# Tauri窗口中按 Cmd+Option+I (macOS) 或 Ctrl+Shift+I (Windows/Linux)
```

### 3. 浏览器扩展调试

1. 打开 `chrome://extensions/`
2. 启用「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择 `apps/browser-extension/.output/chrome-mv3`
5. 点击「Service Worker」查看后台日志
6. 右键插件图标 → 检查弹出窗口

### 4. MCP连接诊断

使用`check-mcp.sh`脚本诊断MCP连接问题：

```bash
# 运行MCP连接诊断
./scripts/check-mcp.sh
```

该脚本会检查：
- 桌面应用是否正在运行
- HTTP服务器是否在监听端口21890
- `/api/health`端点是否正常
- MCP初始化是否成功
- Cursor配置是否正确

## 故障排除

### 常见问题及解决方案

#### 1. Bun安装失败
```bash
# 清理缓存后重试
rm -rf node_modules bun.lockb
bun install
```

#### 2. Tauri构建失败
```bash
# 确保Xcode工具已安装
xcode-select --install

# 更新Rust
rustup update

# 清理Cargo缓存
cd apps/desktop/src-tauri
cargo clean
```

#### 3. WXT开发模式不工作
```bash
# 重新生成配置
cd apps/browser-extension
bun run wxt prepare

# 检查端口是否被占用
lsof -i :3000
```

#### 4. 类型错误
```bash
# 重新构建共享包
cd packages/shared
bun run typecheck

# 重启TypeScript服务器 (VS Code)
Cmd+Shift+P → "TypeScript: Restart TS Server"
```

#### 5. MCP连接问题
- 确保桌面应用正在运行
- 检查`~/.cursor/mcp.json`配置文件
- 确认端口21890未被占用
- 重启Cursor编辑器
