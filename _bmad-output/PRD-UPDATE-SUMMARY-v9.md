## 🎯 数字孪生愿景

### 核心定位

> **「数字孪生，原生 Agent，懂你即决策。」**

Memory Prosthetic 的终极愿景是打造一个**数字孪生（Digital Twin）**——基于用户的所看、所听、所想，生成具备决策能力的个性化 Agent，通过 MCP 协议为所有 AI 助手提供智能支持。

- FR422-FR430: 能力评估、A/B 测试、反馈收集、反馈循环、性能报告、弱点识别、自动优化、性能对比、标准导出

### 章节 10: Agent 生成技术架构 (全新章节)

**5 层架构设计**:

```
1. AI 助手接入层 (MCP Layer)
   └── Claude Desktop, Cursor, ChatGPT

2. Agent 服务层 (Agent Service Layer)
   └── Agent Manager, RAG Engine, Plugin Manager

3. 个性化引擎层 (Personalization Layer)
   └── User Profile Extractor, Decision Style Engine, Context Manager

4. 知识处理层 (Knowledge Processing Layer)
   └── Semantic Search, Knowledge Graph, Vector Store (sqlite-vec)

5. 数据存储层 (Data Storage Layer)
   └── SQLite Database, File System, Vector DB
```

**5 个核心模块**:
1. **用户画像提取器**: 从知识库自动提取多维度身份特征
2. **RAG 引擎**: 检索增强生成，4 种检索策略
3. **决策风格引擎**: 模拟用户决策风格和偏好
4. **Agent 管理器**: 管理生命周期、版本、配置
5. **插件管理器**: 管理插件安全执行和能力扩展

**技术栈选型**:
- MCP 协议: Rust + rmcp SDK
- Agent 运行时: Rust (异步)
- 向量检索: sqlite-vec
- 知识图谱: @antv/g6 + SQLite
- 文本嵌入: all-MiniLM-L6-v2 (ONNX)
- 插件系统: WASM (未来)

### 章节 8: Agent 数据模型 (10 个新表)

**核心实体关系**:
```
用户 (User)
  └── 1 ── 1 用户画像 (user_profiles)
         └── 1 ── * Agent (agents)
                ├── 1 ── * 对话会话 (conversations)
                │      └── 1 ── * 消息 (conversation_messages)
                ├── 1 ── * 插件关联 (agent_plugins)
                │      └── * ── 1 插件 (plugins)
                ├── 1 ── * 性能指标 (agent_metrics)
                ├── 1 ── * 用户反馈 (user_feedback)
                └── * RAG 检索历史 (rag_retrieval_history)
```

**10 个数据表**:
1. `user_profiles`: 用户画像存储
2. `agents`: Agent 配置管理
3. `agent_versions`: Agent 版本历史
4. `conversations`: 对话会话
5. `conversation_messages`: 对话消息
6. `plugins`: 插件定义
7. `agent_plugins`: Agent 插件关联
8. `agent_metrics`: 性能指标
9. `user_feedback`: 用户反馈
10. `rag_retrieval_history`: RAG 检索历史

**完整性约束**:
- 每个用户只有一个活跃画像
- Agent 状态转换验证
- 自动更新消息计数
- 自动更新 Agent 使用时间

### Non-Functional Requirements 增强

**16 条性能指标**:
- RAG 语义检索: Top-10 < 100ms (P0)
- RAG 上下文构建: < 200ms (P0)
- Agent 响应时间: 首字 < 1s (P0)
- Agent 完整响应: < 5s (P0)
- 用户画像提取: 1000 条 < 5s (P1)
- Agent 生成: < 30s (P1)
- 插件执行: < 50ms (P1)

**14 条可靠性指标**:
- 用户画像准确性: ≥ 85%
- RAG 检索召回率: ≥ 80%
- Agent 回答满意度: ≥ 4.0/5.0
- Agent 决策一致性: ≥ 80%
- 插件执行可靠性: ≥ 98%
- Agent 进化有效性: 2 个月后满意度提升 ≥ 15%

**13 条安全指标**:
- 用户画像完全本地存储
- Agent 配置加密存储
- 对话历史加密存储
- 插件沙箱隔离 100%
- 插件权限明确声明
- 敏感数据自动过滤
- 可遗忘性（可删除所有数据）
- 数据可移植性（可导出所有数据）
